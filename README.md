# Everything-From-Scratch-ML
Implementation of core Machine Learning algorithms from scratch using Python — no external ML libraries, just pure logic and math.

# Machine Learning From Scratch 🚀

This repository contains implementations of core **Machine Learning algorithms** built completely **from scratch** — no `scikit-learn`, `TensorFlow`, or `PyTorch`.  
The goal is to deeply understand the mathematics and logic behind each model.

---

## 📘 Contents

| Category | Algorithms / Topics |
|:---|:---|
| **Supervised Learning** | Linear Regression, Logistic Regression, k-Nearest Neighbors (k-NN), Naive Bayes, Decision Trees, Random Forest |
| **Unsupervised Learning** | k-Means Clustering, Principal Component Analysis (PCA) |
| **Reinforcement Learning** | Q-Learning, SARSA |
| **Optimization Algorithms** | Gradient Descent, Stochastic Gradient Descent (SGD) |
| **Evaluation Metrics** | Accuracy, Precision, Recall, F1-Score, Mean Squared Error (MSE), R² Score |
| **Data Preprocessing & Utilities** | Data Cleaning, Feature Scaling, Normalization, Train-Test Split |
